# Food-Over-Fuss

Food-Over-Fuss adalah sistem perencana menu cerdas berbasis AI yang menyusun rekomendasi makanan harian secara personal. Solusi ini mengotomatisasi pemenuhan nutrisi dengan mempertimbangkan preferensi, anggaran, serta kondisi khusus (alergi/diet) untuk meningkatkan efisiensi dan gaya hidup sehat secara konsisten.
